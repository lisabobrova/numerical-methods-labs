# Numerical Methods Labs

This repository contains a series of Python notebooks exploring fundamental numerical methods through implementation, numerical experiments, and error analysis.

## Contents

### Lab 1 — Interpolation and Numerical Integration

Implementation and analysis of global and piecewise Lagrange interpolation, interpolation error and stability, and numerical integration methods including the trapezoidal and Simpson rules.

### Lab 2 — Nonlinear Equations and Iterative Solvers

Implementation of fixed-point iteration and Newton's method for scalar and systems of nonlinear equations, together with Richardson iteration for systems of linear equations. The experiments examine convergence behaviour, error estimates, and sensitivity to method parameters.

### Lab 3 — Numerical Solution of Initial Value Problems

Implementation and analysis of the β-method for scalar and systems of initial value problems, including explicit and implicit cases, accuracy analysis, nonlinear solves, and applications to dynamical systems.
